# AI Native Project

An AI-native chat application with a responsive sidebar, session management, and multi-model support.

## Features

- Chat interface with session management
- Model and voice selection
- Responsive sidebar navigation
- User authentication (Create Account / Login)
- Audio playback support

## Getting Started

### Prerequisites

- Node.js
- npm or yarn

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```
